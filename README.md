# 🍽️ The Gallery Café - Restaurant Web Application

A database-driven web application developed for **The Gallery Café**, a restaurant based in Colombo. The system is designed to improve customer experience and support restaurant operations through online reservations, food ordering, customer management, and staff administration.

## 📌 Project Overview

The Gallery Café web application provides customers with an interactive platform to explore restaurant services, browse food and beverages, register for an account, make table reservations, and pre-order food before visiting the restaurant.

The system also provides separate functionalities for administrators and operational staff to manage restaurant operations efficiently.
